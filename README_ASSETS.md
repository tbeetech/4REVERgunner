## Important Licensing Notes

### Understanding Creative Commons Licenses

- **CC0** - Public domain, use freely, no attribution required
- **CC BY** - Use freely, attribution required
- **CC BY-SA** - Use freely, attribution required, share-alike
- **CC BY-NC** - Non-commercial use only
- **CC BY-ND** - No derivatives allowed

### Best Practices

1. **Always check the license** before using an asset
2. **Keep track of attributions** - create a credits file:
   ```
   CREDITS.txt
   -----------
   Character Model - "Robot" by AuthorName (CC BY 3.0)
   Sound Effect - "Jump" by SoundCreator from Freesound.org (CC0)
   ```
3. **For commercial projects**: Avoid CC BY-NC (non-commercial) licenses
4. **When in doubt**: Contact the creator or choose a different asset
5. **Read the full license** on the asset page, not just the icon

### Attribution Template

When attribution is required, use this format:

```
Asset Name by Creator Name (License)
Source: URL
```

Example:
```
"Epic Sword" by JohnDoe (CC BY 4.0)
Source: https://opengameart.org/content/epic-sword
```

## Tips for Finding Assets

1. **Start with placeholders**: Use Godot primitives first, replace later
2. **Consistent art style**: Choose assets that match visually
3. **Optimize for performance**: Lower poly counts for better framerates
4. **Test before committing**: Import and test assets in Godot before adding to Git
5. **Modify when needed**: Edit models/textures in Blender to fit your style
