# Free Asset Resources

This document lists recommended sources for free game assets (3D models, 2D graphics, audio, textures) suitable for use in 4REVERgunner and other game projects.

## Important: Check Licenses!

Always verify the license before using any asset in your project:
- ✅ **CC0 (Public Domain)**: Use freely, no attribution required
- ✅ **CC-BY (Attribution)**: Use freely, credit the creator
- ✅ **MIT/BSD**: Use freely, include license text
- ⚠️ **CC-BY-SA**: Use freely, but derivatives must use same license
- ⚠️ **CC-BY-NC**: Free for non-commercial use only
- ❌ **All Rights Reserved**: Cannot use without explicit permission

**For 4REVERgunner**: Prefer **CC0** or **CC-BY** assets to keep licensing simple.

## 3D Models & Characters

### OpenGameArt.org
**URL**: [opengameart.org](https://opengameart.org/)
- **License**: Varies (CC0, CC-BY, GPL, etc.)
- **Content**: 2D/3D game assets, sprites, models, textures
- **Filter**: Use search filters to find CC0 or CC-BY only
- **Quality**: Community-contributed, varies in quality
- **Best For**: Prototyping, placeholders, indie games

### Poly Pizza
**URL**: [poly.pizza](https://poly.pizza/)
- **License**: CC0 (Public Domain)
- **Content**: Low-poly 3D models
- **Quality**: Stylized, consistent art style
- **Best For**: Low-poly games, quick prototyping

### Quaternius
**URL**: [quaternius.com](https://quaternius.com/)
- **License**: CC0 (Public Domain)
- **Content**: Ultimate 3D model packs (characters, props, environments)
- **Quality**: High-quality, game-ready
- **Best For**: Complete asset packs, consistent style

### Kenney.nl
**URL**: [kenney.nl/assets](https://kenney.nl/assets)
- **License**: CC0 (Public Domain)
- **Content**: 3D models, 2D sprites, UI, audio
- **Quality**: Professional, consistent, game-ready

## How to Credit Assets

When using CC-BY or other attribution-required assets, include credits in your game:

### In-Game Credits Screen
```
Assets:
- Character models: [Creator Name] (CC-BY 4.0) - [URL]
- Background music: Kevin MacLeod (incompetech.com)
- Sound effects: [Freesound username] (CC0)
- UI icons: game-icons.net (CC-BY 3.0)
```

### In README or Documentation
```markdown
## Asset Credits
- 3D Models: [Kenney.nl](https://kenney.nl/) (CC0)
- Music: "Track Name" by Kevin MacLeod (incompetech.com) (CC-BY 4.0)
```

### Quick Attribution Template
```
[Asset Name] by [Creator] 
License: [CC0/CC-BY/etc.]
Source: [URL]
```

| MIT/BSD | ✅ | ✅ | ⚠️ | ✅ | ❌ |
| GPL | ✅ | ✅ | ✅ | ✅ | ✅ |

- ✅ Compatible
- ⚠️ Compatible but may require derivatives to use SA license
- ❌ Incompatible or complex

## Best Practices

1. **Keep a Credits Document**: Track every asset you use with license info
2. **Download Licenses**: Save a copy of the license text with the asset
3. **Check License Changes**: Licenses can change; use assets as they were licensed when downloaded
4. **Verify Commercial Use**: If selling your game, double-check all assets allow commercial use
5. **Prefer CC0**: Simplest license, no attribution required, no restrictions
6. **When in Doubt, Ask**: Contact the creator if license is unclear
